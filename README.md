# ISE-Design-Suite-Linux
Этот репозиторий направлен на то, чтобы помочь вам с установкой ISE Design Suite на Linux. Разобраться как прошивать платы под Digilent Adept2.

## Проблема (Актуальность)
Программа ISE Design Suite перестала поддерживаться после 2013 года. Последняя и стабльная версия 14.7. 
Её можно установить на Linux. Однако некоторые системы могут жаловаться на неустановленные зависимости.
Поэтому я решил сделать репозиторий, который поможет русскоязычному сообществу разобраться с установкой
ISE Design Suite на Linux.
